# ✨ Essência Elegante

> Plataforma completa de **e-commerce para alfaiataria feminina**, desenvolvida com foco em elegância, desempenho e uma excelente experiência de compra.

---

## 📖 Sobre

A **Essência Elegante** é uma plataforma de e-commerce desenvolvida para comercialização de roupas de alfaiataria feminina.

O sistema foi projetado para oferecer:

- 🛍️ Uma experiência de compra elegante e intuitiva;
- ⚡ Alto desempenho;
- 🔒 Segurança para clientes e administradores;
- 📦 Gerenciamento completo de produtos, pedidos e clientes;
- 📊 Painel administrativo para controle da loja.

---

## 🚧 Status do Projeto

> **Em desenvolvimento**

## 🚀 Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| Next.js | Framework React |

| Prisma ORM | ORM para banco de dados |
| PostgreSQL | Banco de dados relacional |
